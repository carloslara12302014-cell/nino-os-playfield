# Playfield

Playfield is an original, responsive browser-game launchpad with a Windows-inspired desktop appearance, an Opera GX shortcut, an optional Google Search link, category filters, and a local play-guide demo. It was built for a Nino OS-style dashboard request but is not the Nino OS project and is not affiliated with it.

## Run it

Open `index.html` in a modern browser. No install, build step, account, or server is required. The Google Fonts link is optional; the page falls back to system fonts if it cannot load.

## Notes

- Game cards and shortcuts open third-party websites in a new tab. Their availability, content, and age ratings are controlled by those sites and the network you use.
- Use games and websites only where permitted. This page does not bypass network or device restrictions.
- Opera GX opens its official site in a new tab; Playfield does not install or control the browser.
- Google Search is available separately from the Start menu and footer.
- The play guide is a small local demo with preset suggestions. It is not a live AI, does not send messages anywhere, and does not store them.
